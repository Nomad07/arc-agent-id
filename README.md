# Arc Agent ID

A lightweight Python tool for working with AI agent identities on the Arc network using ERC-8004.

## Overview

Arc Agent ID explores how AI agents can use onchain identity, reputation and validation on Arc Testnet.

The project is designed as a simple developer tool for registering and inspecting AI agent identities through ERC-8004.

## Planned Features

- Connect to Arc Testnet
- Register an AI agent
- Retrieve an agent ID
- Inspect agent identity information
- Check agent ownership
- Read agent reputation
- Check agent validation status
- Provide a simple interface for interacting with agent identity data

## Network

The project is currently intended for Arc Testnet.

- Network: Arc Testnet
- Chain ID: `5042002`
- RPC: `https://rpc.testnet.arc.network`

## Requirements

- Python 3.10+
- `web3.py`
- Arc Testnet wallet

## Project Status

Early development.

The current repository contains the initial project structure. ERC-8004 identity functionality will be implemented as the project develops.
